# Blog: roz ka routine (Hinglish)

Sab kuch **Writing desk** se: `https://upsc-owl-sociology.vercel.app/admin/write` (dashboard pe "Writing desk" tile). Har cheez **draft** banti hai. Tum padhte ho, thik karte ho, phir Publish dabate ho. Kuch bhi apne aap live nahi hota.

## Ek baar ka setup (pehla din)
1. `/admin` kholo, pehla admin account banao (pehla user apne aap admin hota hai).
2. Vercel mein `SITE_URL` aur GitHub secrets (`SITE_URL`, `CRON_SECRET`) set hone chahiye (ho chuke hain).
3. Writing desk kholo aur neeche ke 5 tareeko mein se koi ek try karo.

## Roz ke 5 tareeke
| Tum kya karna chahte ho | Desk pe kya karo | Ban kya jaata hai |
|---|---|---|
| Khud likhna | **01 Naya blog likho** | Khaali editor: colours, tables, callouts, FAQ |
| ChatGPT ka answer | **02 ChatGPT se paste**: text daalo, "Draft banao" | Headings, bold, tables ke saath draft |
| Apne notes (Word/PDF/Markdown/HTML) | **03 Notes upload**: file drop karo. PDF ho to "Original PDF attach karo" tick karo | Draft. PDF attach ki to post pe "Notes download karo" box |
| Infographic ya screenshot | **04 Infographic paste**: box pe click, `Ctrl/Cmd+V`, title likho | 1 infographic wala draft. Reader tap karke zoom + download kar sakta hai |
| Kai images | **05 Images ka post**: 2-12 images drop karo, title likho | Gallery wala draft (phone pe 2 columns) |

## Draft ke baad (har baar 3 kaam)
1. **Draft kholo →** dabao, text padho, jahan zaroorat ho thik karo. Image ke niche caption/credit daalo.
2. Sidebar mein **category** aur **syllabus links** (topic/thinker) chuno. AI sirf khaali jagah bharta hai, tumhara likha kabhi nahi badalta.
3. **Publish** dabao (ya **Schedule publish** se samay chuno). Publish pe sitemap, RSS, IndexNow aur Telegram apne aap chalte hain.

## Dhyan rakho
- **Sirf apne notes.** Kisi coaching ke handout/book ka text mat daalo (D15). Copy-paste material draft mein bhi mat rakho.
- PDF **public** hoti hai. Private cheez attach mat karo.
- Scanned PDF (sirf photo wali) padhi nahi jaati: text wali PDF ya Word file use karo.
- Same file dobara daalne par "pehle se hai" aayega aur purane draft ka link milega.
- Kuch na chale to batao: error ka message yahan likha dikhta hai, screenshot bhej do.
